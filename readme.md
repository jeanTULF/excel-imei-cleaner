# 📊 Excel IMEI Cleaner

Herramienta de automatización para el procesamiento y limpieza de reportes Excel relacionados con IMEI.

## 🚀 Descripción

Este proyecto permite procesar múltiples archivos Excel de forma automática, estandarizando su estructura, corrigiendo formatos y eliminando la necesidad de manipulación manual archivo por archivo.

---

## ⚙️ Funcionalidades

* 📂 Selección de carpeta con múltiples archivos Excel
* 🔄 Procesamiento masivo automático
* 🧹 Estandarización de encabezados
* 📅 Normalización de formato de fechas

---

## 🧠 Tecnologías utilizadas

* Python
* Pandas
* Tkinter
* OpenPyXL

---

## ▶️ Uso

### Opción 1: Ejecutable (.exe)

1. Ejecutar `excel_cleaner.exe`
2. Seleccionar la carpeta con los reportes
3. Esperar a que finalice el proceso
4. Revisar la carpeta `/fix` generada automáticamente

---

### Opción 2: Script Python

```bash
python excel_cleaner.py
```

---


## 📌 Notas

* No requiere instalación cuando se utiliza el ejecutable
* Compatible con archivos `.xls` y `.xlsx`
* Mantiene el orden de columnas basado en un estándar definido

---

## 💡 Caso de uso

Este proyecto fue desarrollado para reducir tareas manuales repetitivas en el procesamiento de reportes operativos, mejorando la eficiencia y reduciendo errores humanos.
